# Учебное приложение: формализация ETL-процесса

*Это приложение подготовлено специально для семестрового проекта по документированию ПО.
Оно отсутствует в исходной опубликованной статье и не является её частью.*

Описанный в статье конвейер извлечения, преобразования и загрузки данных
можно условно представить следующей формулой LaTeX:

$$
D_{\mathrm{out}} = L\!\left(T_C\!\left(E(F)\right)\right),
$$

где $F$ — входные файлы отчётов, $E$ — извлечение данных,
$T_C$ — преобразование по правилам конфигурации $C$,
$L$ — загрузка преобразованных данных в целевое хранилище,
$D_{\mathrm{out}}$ — полученные данные.

Формула служит **иллюстрацией синтаксиса LaTeX**, а не отдельным результатом
исследования или новым утверждением опубликованной статьи.
