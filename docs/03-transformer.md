# Модуль преобразования данных (Transformer)

Модуль Transformer реализует логику основного этапа ETL – преобразования входных данных к целевому виду. Особенность данного модуля в том, что правила обработки заданы во внешнем конфигурационном файле, в нем задается информация, необходимая для распознавания и унификации столбцов входной таблицы:

- Ключевые слова для поиска по заголовкам и содержимому ячеек. Например, для категории продуктов могут использоваться слова «шампунь», «гель» и др.

- Длины числовых значений, характерные для определенных реквизитов. Например, числа длиной 13 или 14 символов могут указывать на штрихкод товара.

- Комбинации признаков для сложных полей, которые определяются несколькими элементами сразу (например, адрес может требовать наличие названия города и улицы в тексте).

- Описание выходных колонок – список колонок, которые должны присутствовать в результирующей таблице, с указанием для каждой колонки специфического метода поискаКонфигурационный файл таким образом служит центральным хранилищем знаний о структуре данных. При необходимости изменить структуру итогового отчета или логику распознавания данных достаточно отредактировать этот файл, что существенно упрощает поддержку системы.
