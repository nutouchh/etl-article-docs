# Алгоритм трансформации данных

При поступлении нового отчета сервер вызывает соответствующий метод Transformer, передавая ему извлеченные из файла данные в виде DataFrame. Преобразование выполняется по шагам:

1. Загрузка конфигурационного файла.

2. Парсинг структуры таблицы. Выполняется определение структуры таблицы (матричная, иерархическая, простая) и при необходимости приведение к простому виду.

3. Предобработка таблицы. Выполняется очистка исходных данных.

4. Динамическое формирование выходных колонок с учетом конфигурации.

5. Завершение трансформации. В итоге формируется выходной DataFrame со всеми требуемыми колонками в нужном формате. Если какой-либо из поисковых методов не смог найти соответствующие данные, в результирующую колонку просто помещаются пустые значения (NaN), чтобы сохранить структуру.

## Методы поиска данных

Модуль Transformer содержит набор универсальных методов, каждый из которых реализует определенный способ поиска и извлечения данных из таблицы:

- методы очистки исходной таблицы (удаление пустых строк, столбцов, поиск заголовка таблицы),

- нахождение max совпадений с ключевыми словами в содержимом,

- нахождение max совпадений с ключевыми словами в заголовке,

- нахождение содержимого в числовом виде и с фиксированной длиной,

- нахождение max совпадений с ключевыми словами в содержимом с учетом фильтрации    ложных слов.

Конфигурация указывает, какой из этих методов применять для каждой выходной колонки.
