# Архитектура системы

Разработанное веб–приложение имеет клиент–серверную архитектуру с выделением модулей (рисунок \ref{fig:architecture}).

![Архитектура разработанной ETL-системы](assets/etl-architecture.png){#fig:architecture width=80%}

![Архитектура разработанной ETL-системы ТЕСТ](assets/new-for-test.png){#fig:architecture2 width=80%}

Основные компоненты серверной части приложения:

- Extractor – модуль извлечения данных. Содержит набор классов для считывания загруженных файлов различных форматов (Excel, CSV и др.) и преобразования их содержимого в DataFrame с использованием библиотеки pandas.

- Transformer – модуль преобразования данных. Выполняет очистку и трансформацию извлеченных таблиц по заданным правилам, приводя данные к унифицированной структуре.

- Loaders – модуль загрузки результатов. Отвечает за сохранение преобразованных данных в целевое хранилище.

- Оркестратор ETL–процесса – управляющий компонент (pipeline), который последовательно вызывает нужные модули для каждого загруженного отчета. Оркестратор отслеживает успех или сбой на каждом этапе и обновляет статус обработки.
